# Production Fix Report

## Firefox save lifecycle

All save entry points now join one in-flight promise. The request owns a cloned snapshot; the response may adopt server ID/version without replacing edits made after the request began. First-save navigation is performed only after persistence succeeds, checked for router failure, and temporarily bypasses the leave guard only for that confirmed transition. Publish stops when its prerequisite save fails. Dashboard queries are invalidated after persistence.

The DOM emits `vip:dashboard-save` events with `started`, `joined`, `persisted`, `navigated`, `failed`, `finished` phases and no dashboard content or credentials. Backend timing is captured by Playwright request/response timing. The regression deliberately dispatches two keyboard saves and requires exactly one create plus one editor update.

## PostgreSQL checkout

Local and CI integration URLs now use `postgresql+asyncpg://...@127.0.0.1:5432/vip_test?ssl=disable`. This is scoped to the local non-TLS container. Production TLS behavior is untouched. The connection timeout remains two seconds.

## End-to-end dashboard parity

The immutable published definition is the shared contract for viewer, PDF, PNG, CSV, JSON, scheduled delivery, and email attachment generation.

- Widget type, title, layout x/y/w/h, filters, formatting, interactions, accessibility label, lock/hidden state, and content round-trip through the editor API.
- The API accepts every frontend widget type.
- PDF and PNG apply exact 12-column grid coordinates and render KPI, table/pivot, text/filter/image, bar/column/stacked/map, line/area, scatter, pie/donut, gauge/progress families.
- JSON contains metadata, the complete canonical definition, and safe widget results.
- CSV identifies widget ID/type and grid coordinates before tabular values.
- PDF keywords and PNG text metadata embed the complete definition for machine verification.
- Unicode/Arabic uses DejaVu plus deterministic reshaping/bidi ordering in API and worker images.
- Scheduled delivery accepts PDF, PNG, CSV, and JSON; email composition preserves the generated bytes exactly.

Evidence is under `artifacts/qa/production-remediation/dashboard-parity`.

## API contract validation

The new integration sweep loads the live OpenAPI document, requires at least 192 paths and 247 operations, resolves every local `$ref`, checks operation IDs/tags/summaries/path parameters/2xx declarations, then calls every operation anonymously with invalid UUIDs or empty bodies. Any 5xx or malformed standard error envelope fails the suite. Existing integration suites continue to cover authenticated request schemas, RBAC, forbidden requests, tenant isolation, suspended users, pagination/filtering/sorting, payload bounds, and mutation behavior.

## Conditional decisions

XLSX and archived-user lifecycle are deliberately absent from production. Their controls are not exposed. CSV/TSV/text upload and suspend/activate are the supported alternatives.
