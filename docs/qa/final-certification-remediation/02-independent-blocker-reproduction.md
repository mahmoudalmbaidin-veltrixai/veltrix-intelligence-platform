## Guardrails for implementation

- No timeout increase, fixed-sleep reliability patch, mock substitution for integration behavior, authorization relaxation, destructive migration, or data reset is an acceptable fix.
- A test that fails during setup is reported as setup failure, not product coverage.
- Retries and first-run failures remain separate in all final totals.
