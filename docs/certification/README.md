# Certification evidence

Certification material is organized by purpose:

- `final-product-audit/` contains the latest repeatable product-readiness audit package and its revision-specific report;
- `productization/` contains historical market, architecture, provider, and go-live planning documents;
- `qa/legacy/` preserves earlier remediation reports moved from the repository root;
- `../qa/` contains later structured QA and release-freeze evidence.

Every certification or audit applies only to its recorded Git SHA, configuration, services, and test scope. It must not be promoted to a current claim without rerunning the stated gates.

Credential registers, private workbooks, raw legacy evidence, local reports, and generated browser artifacts are stored below ignored `artifacts/` and are not repository content.
